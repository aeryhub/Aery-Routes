# Catt-Routes

Auto Play routes for CattHub.

- `Games/EToH/<Area>/<Tower>.lua` - Eternal Towers of Hell
- `Games/TEA/<Area>/<Tower>.lua` - The Eternal Abyss
- `Games/CSCD/<Area>/<Tower>.lua` - Caleb's Soul Crushing Domain

Routes copied from [MaybeIsRealZack/Project-EToH-Script](https://github.com/MaybeIsRealZack/Project-EToH-Script) (commit a44c664), licensed under GPL-3.0 (see LICENSE).
